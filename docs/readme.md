# Spot 문서

Spot은 개인용 macOS 런처(⌥Space) + 키보드 화면 접근 도구(⌃Space)에,
키 리맵(Karabiner 대체)·모니터 밝기/볼륨(MonitorControl 대체)·앱별 한/영 전환
(Input Source Pro 대체) 상시 유틸리티를 더한 앱이다.
빠른 시작은 [루트 README](../README.md), 그 이상은 아래 문서를 본다.

## 추가 후보 (미착수)

아직 착수하지 않은 기능 후보 모음. 도메인별 세부 후보는 각 설계 문서의 로드맵 참조
([display-control.md](display-control.md) · [window-management.md](window-management.md)).

### 기존 기능 확장

- **북마크**: Safari·Firefox 지원 (현재 Chromium 계열만)
- **창 전환기**: 앱이 아니라 열린 창 단위 검색·전환
- **클립보드**: 긴 텍스트 미리보기
- **파일 검색**: Quick Look 미리보기(Space), 최근 문서 목록
- **계산기**: 날짜 계산(`3주 후`, `D-day`), 색상 변환(`#ff5500 to rgb`), 진법 변환
- **웹 검색**: 커스텀 검색 엔진 사용자 등록 (현재 g/yt/gh/nv 하드코딩)
- **시스템 액션**: Wi-Fi·블루투스 토글, 방해금지 모드, 해상도 전환
- **잠자기 방지**: 디스플레이만 끄고 시스템 유지 옵션, 특정 앱 실행 중 자동 세션

### 새 기능

- **타이머·알람** — `타이머 10분`, 메뉴바 카운트다운 (awake 세션 UI 패턴 재사용)
- **프로세스 종료** — `종료 크롬`, `quit slack` (강제 종료 포함)
- **macOS 단축어(Shortcuts) 실행** — `shortcuts://` URL로 권한 없이 가능
- **사전 검색** — `dict` 접두사로 시스템 사전 열기
- **밝기 스케줄** — 시간대별 모니터 밝기 자동 조절 (Lunar 방식, DDC 엔진 재사용)
