# 기능 상세

Spot의 모든 기능과 키맵. 구현 방식이 궁금하면 [architecture.md](architecture.md) 참조.

---

## 1. 런처 (⌥Space)

⌥Space로 열고 닫는다. 포커스를 뺏지 않는 오버레이라 닫으면 쓰던 앱으로 그대로 복귀한다.
Esc는 Alfred 방식: 입력이 있으면 지우고, 비어 있으면 닫는다.
↑↓로 선택 이동, Enter로 실행. 모든 결과는 fuzzy 점수 + frecency(사용 학습)로 랭킹된다.

### 1-1. 앱 검색

- 영어 이름, **한글 현지화 이름**("음악", "캘린더", "터미널"), **한글 초성**("ㅋㅋㅇ" → 카카오톡) 모두 매칭
- "환경설정"처럼 현지화 이름("시스템 설정")과 다른 익숙한 별칭도 등록되어 있다
- 스캔 대상: `/Applications`, `/System/Applications`, 각 Utilities, `~/Applications`, Finder. 5분마다 재스캔
- 자주 여는 앱은 위로 올라온다 (빈 입력 상태에서는 frecency 순 목록)

### 1-2. 파일 검색

- 3글자 이상 입력 시 Spotlight 인덱스(NSMetadataQuery)로 홈 디렉터리에서 파일명 검색
- 250ms 디바운스, 최대 20건, `node_modules`·`.git`·`Library` 등 제외
- **Enter** = 열기, **⌥Enter** = Finder에서 보기

### 1-3. 계산기 · 단위 변환

- 사칙연산·거듭제곱·괄호: `1+2*3`, `2^10`, `(3+4)/2` — Enter로 결과 복사
- 단위 변환: `10km to mi`, `30c to f`, `1gb to mb` — 길이/무게/온도/부피/데이터
- 복사한 결과는 클립보드 히스토리에도 기록된다

### 1-4. 클립보드 히스토리

- `cb` 또는 `클립` 으로 진입, `cb 검색어`로 필터
- 텍스트만 저장, 최대 300개, 디스크 영속 (`~/Library/Application Support/Spot/clipboard.json`)
- **Enter** = 클립보드에 복사 + 자동 붙여넣기(손쉬운 사용 권한 필요, 없으면 복사까지만), **⌥Enter** = 복사만
- 붙여넣은 항목은 히스토리 최상단으로 올라온다 (MRU)

### 1-5. 시스템 액션

한글/영문 키워드 fuzzy 매칭: 잠자기 · 화면 잠금 · 휴지통 비우기 · 다크 모드 전환 · 화면 보호기 · 재시동 · 시스템 종료 · Spot 종료

### 1-6. 잠자기 방지 (Amphetamine 방식)

| 입력 | 동작 |
|---|---|
| `깨어있기`, `awake`, `카페인`, `커피` | 무기한 세션 시작 |
| `awake 30분`, `카페인 2시간`, `awake 1시간 30분`, `awake 90m`, `awake 45` | 지정 시간 세션 (숫자만 쓰면 분) |
| 세션 중 같은 키워드 | "깨어있기 해제 (남은 시간)" 이 최상단 |

- 세션 중 메뉴바 아이콘이 ☕️로 바뀐다. 메뉴바 메뉴에서도 시작/해제 가능
- IOKit 전원 어설션 사용 — **권한 불필요**, 앱이 종료되면 자동 해제
- 한계: 뚜껑을 닫으면 잠든다 (공개 API의 한계, 외장 모니터+전원 연결 시 제외)

### 1-7. UI 요소 검색 (Shortcat 방식)

`;`로 시작하면 **최전면 앱의 클릭 가능한 요소**를 검색한다:

- `;` 만 입력 → 전체 요소 목록 (버튼·링크·메뉴·입력란 등, 역할별 아이콘)
- `;저장`, `;뒤로`, `;bookmark` → 요소 이름 fuzzy 검색 (한글 초성 포함)
- **Enter** → 패널이 닫히고 해당 요소 클릭

접근성 트리는 비동기로 수집되고 5초간 캐시되어, 같은 앱이면 타이핑마다 즉시 필터링된다.
손쉬운 사용 권한 필요.

### 1-8. 웹 검색

- `g 검색어`(구글) / `yt 검색어`(유튜브) / `gh 검색어`(깃허브) / `nv 검색어`(네이버)
- 어떤 결과에도 매칭이 없으면 목록 맨 아래에 구글 검색 폴백이 항상 붙는다

## 2. 키보드 화면 접근 (⌃Space)

마우스 없이 화면을 조작하는 4개 모드. **⌃Space 순환: 힌트 → 스크롤 → 종료**, 힌트에서 `/` → 그리드, `.` → 창 모드.

```
⌃Space ──→ 힌트 모드 ──⌃Space/Tab──→ 스크롤 모드 ──⌃Space/Esc──→ 종료
              │
              ├── "/" ──→ 그리드 모드
              ├── "." ──→ 창 모드 (창 배치)
              └── (요소 수집 실패 시 자동으로 그리드 모드)
```

### 2-1. 힌트 모드 — 보이는 요소 클릭 (Homerow/Vimium 방식)

⌃Space를 누르면 최전면 앱의 클릭 가능한 요소마다 노란 라벨(`A`, `SD` …)이 뜬다.

| 키 | 동작 |
|---|---|
| 라벨 글자 | 후보가 좁혀지고, 라벨이 완성되면 해당 요소 클릭 |
| Delete | 한 글자 지우기 |
| Tab | 스크롤 모드 전환 |
| `/` | 그리드 모드 전환 |
| Esc | 취소 |

- **한글 입력 상태에서도 동작한다** (물리 키 위치 기준이라 한/영 전환 불필요)
- 메뉴 막대 항목에도 라벨이 붙는다 — 선택하면 메뉴가 열리고 방향키로 탐색
- 26개 이하면 1글자, 그 이상이면 2글자 라벨 (홈로우 키 우선)
- Electron 앱(VSCode·Slack 등)은 접근성 트리를 지연 생성해 첫 호출이 한 박자 늦을 수 있다

### 2-2. 스크롤 모드 — HJKL

진입 시 포인터가 최전면 창 중앙으로 이동하고 하단에 안내 HUD가 뜬다.

| 키 | 동작 |
|---|---|
| H / J / K / L | 좌 / 아래 / 위 / 우 스크롤 (꾹 누르면 키 반복으로 연속) |
| D / U | 반 페이지 아래 / 위 |
| Esc 또는 ⌃Space | 종료 |

모드 중 다른 키는 모두 무시된다(대상 앱으로 전달되지 않음).

### 2-3. 그리드 모드 — 접근성 트리 없는 앱 폴백 (warpd/keynav 방식)

일부 게임·커스텀 렌더링 앱은 접근성 정보가 없어 힌트를 붙일 수 없다.
이때 화면 좌표 자체를 키보드로 좁혀간다:

| 키 | 동작 |
|---|---|
| Q W E / A S D / Z X C | 화면을 3×3 분할, **자판 배치 = 화면 배치**로 칸 선택. 누를 때마다 재귀 분할 |
| Return 또는 Space | 현재 영역 중앙 클릭 |
| Esc 또는 ⌃Space | 종료 |

- 칸을 고를 때마다 포인터가 영역 중앙으로 이동한다 (호버 효과 확인 가능)
- 3~4번이면 2560px 화면에서 ~30px 정밀도
- 선택 영역 밖은 어둡게 표시, 노란 격자와 키 라벨 오버레이

### 2-4. 창 모드 — 창 배치 (Rectangle 대체)

힌트 모드에서 `.` 로 진입. 모드가 유지되어 연속 조작 가능 — "H(왼쪽 절반) → H(⅔) → K(상단)" 식.
설계 배경은 [window-management.md](window-management.md) 참조.

| 키 | 동작 |
|---|---|
| H / J / K / L | 좌 / 하 / 상 / 우 절반. **같은 키 반복 = ½ → ⅔ → ⅓ 사이클** |
| Y / U / B / N | 코너 1/4 (좌상 / 우상 / 좌하 / 우하 — 자판 위치 = 화면 위치) |
| M | 최대화 (메뉴바·Dock 제외 가용 영역) |
| C | 중앙 정렬 (크기 유지) |
| `-` / `=` | 작게 / 크게 (중심 유지 ±30px) |
| `[` / `]` | 이전 / 다음 디스플레이로 이동 (상대 위치·크기 비율 유지) |
| R | 복원 — 첫 스냅 이전 프레임으로 |
| Esc 또는 ⌃Space | 종료 |

**전역 단축키** — Rectangle에서 쓰던 조합 그대로, 모드 진입 없이 바로 실행:
⌥⌘화살표(절반) · ⌃⌘←/→(위 코너) · ⌃⇧⌘←/→(아래 코너) · ⌥⌘F(최대화) · ⌥⌘C(중앙) ·
⌃⌥⇧↑(높이 최대화) · ⌃⌥⇧←/→(작게/크게) · ⌥⇧⌘←/→(디스플레이 이동) · ⌃⌥⌫(복원)

### 클릭 실행 방식 (공통)

- `AXPress` 접근성 액션 우선 — 포인터를 움직이지 않고 실행
- 실패하거나 텍스트 입력란(캐럿 위치가 중요)은 실제 마우스 클릭 이벤트 합성

## 3. 키 리맵 (Karabiner-Elements 대체)

메뉴바 → "키 리맵" 토글. 기본 켜짐. 전 키보드에 적용:

| 리맵 | 용도 |
|---|---|
| 우측⌘ → F18 | F18은 시스템 설정 "이전 입력 소스" 단축키 → **한/영 전환** |
| Caps Lock → 좌⌃ | 내장 키보드에서도 HHKB처럼 Control 위치 통일 (HHKB는 하드웨어가 이미 Control이라 무영향) |

- macOS 내장 HID 리맵(hidutil)이라 **권한 불필요**, 보안 입력(암호 필드)에서도 동작
- Spot이 시작할 때·키보드가 연결될 때·잠자기에서 깰 때 자동 재적용
- 매핑은 시스템 속성이라 Spot을 종료해도 유지된다 (끄려면 메뉴에서 토글)
